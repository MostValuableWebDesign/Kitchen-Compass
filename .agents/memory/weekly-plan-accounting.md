---
name: Week-wide plan accounting
description: Rules for reservations, quantified shortages, and leftovers across an entire selected meal week.
---

Planned meals share one reservation budget for the selected week. Generation and replacement must rank each slot against inventory after reservations from earlier slots; physical inventory stays unchanged until cooking.

**Why:** Treating every slot as if it had the full inventory allows the same ingredient to be promised multiple times and makes shopping needs unreliable.

**How to apply:** Keep known shortages quantified and separate from unknown-quantity confirmations. Reserve leftover portions by leftover record, release those reservations when plan slots change, and consume them with a transaction id so repeated completion cannot deduct twice.
